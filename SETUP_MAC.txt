OTHERGA MES SETUP FOR MAC
========================

WHAT YOU HAVE:
- OtherGames-Complete.zip - Complete games package with all 12 games + Git history

GETTING STARTED:

1. Extract the ZIP file
   - Double-click OtherGames-Complete.zip
   - A folder named "OtherGames" will be created

2. Run the games
   - Open the OtherGames folder
   - Double-click "index.html"
   - Your default browser will open with the menu

3. Play any game
   - Click on any game title from the index
   - Each game is fully playable

CONTINUING DEVELOPMENT:

1. Edit games in a text editor
   - Use any text editor (TextEdit, VS Code, Sublime, etc.)
   - Right-click any .html file → "Open With" → choose editor
   - Make your changes and save

2. Test changes
   - Refresh the browser (Cmd+R) to see changes
   - No compilation or build step needed

3. Debug with Developer Tools
   - Press Cmd+Option+I to open Developer Tools
   - Check Console for any errors
   - Inspect HTML/CSS directly

GITHUB INTEGRATION:

This package includes full Git history! To continue pushing to GitHub:

1. Open Terminal and navigate to the OtherGames folder:
   cd /path/to/OtherGames

2. Check Git status:
   git status

3. After making changes, commit and push:
   git add -A
   git commit -m "Your message here"
   git push

4. Your changes will go to: https://github.com/leeharkis/Games

The .git folder is included in the package with all commit history.

GAME CONTROLS QUICK REF:

Elite Space Combat:
- Arrow Keys = Pitch/Roll
- W/S = Speed
- Space = Fire
- L = Land on planet

Sudoku:
- Click cells, click numbers
- Double-click cell number to select that number

Dots:
- Drag to connect same-color dots
- 4+ circles = more points

Chess:
- Click piece, click destination

Tetris:
- Arrow keys to move, Space/Up to rotate

Daredevil Denis:
- Arrow keys / WASD

NOTES:
- High scores are saved automatically in browser
- All files are self-contained - works offline after first load
- No server needed - just open index.html
- All games are single HTML files for easy editing
- Git history is preserved - all commits from Windows are included
- You can continue making commits from Mac and they'll sync to GitHub

Questions? Check README.md for more details.

Have fun coding! 🎮
